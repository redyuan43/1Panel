02 · 私密凭证接入

已安装本地素材上传组件

  1. 在本页创建专用 Token。请你本人打开 Windows 文件管理器，在地址栏输入 %USERPROFILE%\.workbuddy\h3-bridge，双击 configure-h3.cmd。
  2. 只在弹出的「H3 本机连接设置」密码表单粘贴 Token，点击检查并保存。组件只检查认证和工具列表，不唤醒后台、不生成视频。
  3. 保存成功后，在 WorkBuddy 的 H3 MCP 上点击重连。保留本地 stdio 连接，不要导入远程向导覆盖它，否则会失去本地素材上传入口。
仅使用远程 HTTPS MCP 的接入方式
  1. 下载「原生认证向导」，在 WorkBuddy「专家 → 我的专家」导入并打开「H3 工作室连接向导」。连接依赖时应弹出 H3 私人访问令牌 表单。
  2. 只在该密码表单填写专用 Token；没有表单时停止，不把 Token 粘进聊天或普通 JSON。
  3. 同名连接器冲突时，先确认现有连接不是本地素材组件，不覆盖其他连接器。
