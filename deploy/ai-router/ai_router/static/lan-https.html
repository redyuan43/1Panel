02 / 信任证书

安装到实际运行应用的设备

下载 CA 公钥证书

只下载公开证书，不包含服务器或 CA 私钥。请通过可信的控制台地址下载并核对指纹。

安装指引

  1. 双击下载的 ai-router-lan-ca.crt，选择“安装证书”。
  2. 选择“当前用户”，再选择“将所有证书放入下列存储”。
  3. 选择“受信任的根证书颁发机构”，完成安装。
  4. 完全退出并重新打开调用应用，再填写上方地址和自己的 API Key。

Ubuntu / Debian：在证书下载目录执行：

sudo install -m 0644 ai-router-lan-ca.crt /usr/local/share/ca-certificates/ai-router-lan-ca.crt
sudo update-ca-certificates

然后重新打开调用应用。

  1. 打开“钥匙串访问”，把证书导入“系统”钥匙串。
  2. 打开证书的“信任”，将 SSL 设为“始终信任”，按系统提示确认。
  3. 重新打开调用应用。

浏览器、容器、虚拟环境或部分应用可能使用独立证书库。网页不能自动向系统安装证书；在 nano3 安装也不会使另一台 Windows 自动信任。
