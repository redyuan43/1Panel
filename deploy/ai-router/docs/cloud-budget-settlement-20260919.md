# 云预算结算修复（未部署）

## 本次改动

- 请求前按输入和输出上限预留，非流式在读完响应后结算；流式在最终 usage 到达后结算。不再在收到 HTTP 成功头时把预留额直接当成实际费用。
- 使用上游实际输入、输出、缓存命中 token；DeepSeek 官方 Flash 端点按已核对的版本化峰谷价结算。预留时固定价格，避免结算期间配置变化。
- usage 缺失、格式冲突或断流时保留保守估算并记入 estimated_spent_usd，不当成零费用。相同预留重复完成/清理不会重复扣账。
- 缺缓存价格的其他端点继续使用保守输入单价，但明确归类为估算。
- 云预算不足返回 402 和明确的 Router 云预算提示；TPM 限流仍为 429。
- 不修改本地优先、分时云选择、密钥或客户端配置。

2026-09-19 核对官方页：https://api-docs.deepseek.com/quick_start/pricing/

Flash 自 2026-09-10 04:00 UTC 生效。峰时缓存命中/未命中/输出为每百万 token 0.006/0.3/1.2 USD，谷时减半；工作日 UTC 01–04、06–10 为峰时。仅应用于官方 api.deepseek.com 和列明的 Flash 别名，其他网关不套用。价格模块保留版本生效时间，不能用于更早的记录。

## 历史账本边界

现有 spent_usd 含历史估算，部署新代码不会自动纠正历史数据。只读工具 scripts/audit-deepseek-budget.py 可从 SQLite 审计记录生成逐请求实测费用清单，未知用量单列。该工具不写账本，输出不能直接覆盖全供应商月账本：必须保留其他供应商费用、未知费用以及在途预留。

生产修正需先备份，核对原账本覆盖范围及费率，排除重复请求/尝试，再经用户确认执行。不得直接清零或单纯抬高限额掩盖问题。
