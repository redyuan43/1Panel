# 本地会话识别与固定设备调度

已确认续请求优先保留所属分支当前设备；新任务仍在满足健康、能力、上下文与容量的本地候选中均衡分配。移除基于首字耗时预测的主动迁移，保留故障、能力不足、排队超时及用户明确切换。每 5 秒复查容量，沿用 120 秒等待上限。设备亲和不代表计算缓存命中。

v5 历史指纹兼容带正文的工具调用拆分，校验正文、调用 ID、参数、结果及图片；仅用于关联，不改写模型输入。旧版本索引、共同开场及歧义不能直接继承设备。有效加密归档后台重建独立索引，原文不写入 Redis。候选更新为原子操作，有界多候选防止并发覆盖。

独立分支依据 parent_branch_id 保持亲和，不以整个会话最后完成的分支否定兄弟分支。真正只匹配到最新分支的旧祖先仍拒绝继承；无法证明关系、循环或超过 128 层时返回未确认。近期占用按客户端与会话计数，续请求不重复增加分支占用。

审计显示关联证据、匹配边界和继承设备；历史预测记录保持可读。工具定义和原生输入变化仍可能引起 prefill，与调度稳定分别评估。

验证：独立 HEAD 加本提交片段快照的 60 项 CPU 回归通过，覆盖并行分支交错续请求、旧祖先、歧义、字段保全与固定调度。原始故障归档的 CPU 回归正确选择最近 AI 分支，无模型推理重放。生产镜像测试包含独立 Redis 原子并发回归。Router/Control 更新后健康及鉴权检查通过，模型与 LMCache 未重启，缓存未清理。8–10 轮真实任务的设备稳定性、实际缓存比例和首字时间须另行验收。

回滚只需在无在途请求窗口恢复此前 Router/Control 镜像；保留旧历史索引、Redis 和模型缓存。部署与回滚镜像及检查结果保存在部署主机的本轮实验记录中，实验环境、对话及凭据不进入提交。
