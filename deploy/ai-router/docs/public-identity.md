# 思源公开模型身份

AI Router 可以向普通 API 客户端隐藏真实模型、节点和物理 deployment，
统一使用公开品牌身份：

- 中文名称：`思源`
- 英文名称：`SIYUAN`
- 公开模型 ID：`siyuan/auto`
- 默认身份回答：`我是思源（SIYUAN），由思源智能路由服务提供的统一 AI 助手。`

## 默认状态

代码中的身份资料已经预填，但 `identity.enabled=false`。部署代码不会自动改变
当前客户端行为。管理员需要在“策略设置 / 公开模型身份”检查资料并启用。

启用后：

- `/v1/models`只公开调用方有权使用的 `auto`和`siyuan/auto`。
- `siyuan/auto`内部进入智能路由；只拥有一个旧显式模型权限的账号继续映射到
  原获准模型，不扩大权限。
- 旧真实模型 ID仍可作为兼容入口调用，但响应只显示思源身份。
- Chat和Responses请求都会注入稳定身份策略，不依赖用户语言或关键词。
- JSON、SSE、响应头和错误中的完整内部模型 ID、endpoint、deployment、
  GPU UUID及内部地址会被替换。
- 管理台、路由审计和加密训练归档仍保留真实路由信息。

## 缓存影响

身份策略内容由配置生成固定 revision。相同 revision不会随请求变化，可以参与
后端prefix cache。修改名称、说明或身份回答后，已有会话下一轮需要对新的系统
前缀执行一次prefill，之后重新命中缓存。

## 安全边界

身份策略参考 Hermes Agent 的稳定 SOUL/system prompt机制，不使用关键词表。
模型仍可能尝试推断自身家族，因此 Router还会确定性过滤完整内部标识。系统允许
正常讨论 Qwen、DeepSeek、GPT等通用技术名词，不会全局替换模型家族名称。

启用前应逐个真实端点使用多语言、间接询问和提示注入问题进行验收。身份提示本身
不等于数学意义上的绝对防泄露。
