# 生图策略与可靠性交付

## 范围与状态

生图专用实现；不启用或修改 H3 / 视频调度。生产资格与代码合并分别记录。
NX5 先接入，NX6 完成其他任务交接后独立验收；NX7 不分配。
候选配置默认关闭，横屏 1280×720 尚须真实验收。

## 策略入口

管理台 → 策略设置 → 生图策略；其中“图片任务、下载结果与事件日志”链接进入 `/media/legacy`。固定流程卡片复用草稿、验证、激活、回滚。
`image_generation` 为唯一的新图片路由策略源：本地优先；忙时允许云端；不可用默认排队；
队列 10、排队 1800 秒；Codex 为云端通道；Qwen 付费备用默认关闭。
`PUT /api/settings` 不允许直接激活此配置段，必须使用现有 `/api/policy` 草稿流程。
版本验证仅证明配置合法，不代表模型已加载、节点已验收或生产调用已通过。
账号的云端许可、仅本地、模型授权、任务额度和付费额度仍为硬约束。

新独立图片任务及新图片创作任务持久保存完整策略快照、版本与指纹。幂等重试先恢复原任务；激活或回滚不修改旧任务。
旧媒体设置仍保留兼容任务所需值，新图片队列与路由不读取旧队列值。
媒体总开关、Codex资格、磁盘保护属于运行准入，仍有效。

## 接口

- 图片生成/编辑增加可选 `execution=local|cloud`，未指定时按策略。
- 明确模型和通道冲突返回400；禁止云端返回403；无兼容本地配方返回422。
- 管理员 `GET /api/media/image-resources` 查看资格、忙闲、在途任务；不提供密钥或节点URL。
- 管理员 `GET /api/media/images/{id}/events?after=序号` 分页查询任务事件。
- `POST /v1/images/{id}/delivery` 接收 `{artifact_id,sha256}`，核对账号和归档文件元数据。
  记录为“客户端报告下载”，不是服务器独立证明客户端文件仍存在；重复回执不重复记录。
- 对外任务仅返回通道、策略版本/指纹和交付摘要，不暴露内部资源标识。

## 本地执行与恢复

媒体进程通过 `AI_ROUTER_IMAGE_EXECUTORS_FILE` 读取独立图片池，避免与视频配置混用。
节点须同时 configured、enabled、qualified 且配方兼容，最后实时探测。
`busy` 和 `unavailable` 分别处理。每张物理资源只允许一个图片任务；进程有单worker文件锁。
未知发送结果保留原操作号与资源；只查原执行，取消未确认不释放；10分钟后提示人工核实。
队列/历史中操作标记可恢复 ComfyUI prompt_id，历史消失不代表可重投。
取消只针对本任务，不能调用 ComfyUI 全局 interrupt。

## WorkBuddy

普通图片不进入创作阶段管理。使用：

```text
image --operation-id OP --prompt "原始需求" --aspect-ratio landscape --output "wallpaper.png"
deliver --operation-id OP --seconds 30
```

保留 OP，重复 deliver 查询和下载同一任务；下载文件哈希匹配则复用，不覆盖其他文件。
下载完成但服务端回执失败仍返回本地文件。审核拒绝停止自动重试，不推断版权原因。
上游 failure=null 时只能报告缺少结构化原因，保留任务号供诊断；不按日志时间猜测关联。

## 发布与回滚

1. 从已验证提交构建窄范围候选，记录基线/文件哈希；不要从主目录混合改动构建。
2. 准备独立持久图片池与每节点适配器目录、私网地址、凭证和配方；使用现有依赖环境。
3. 明确 NX5 GPU 测试和服务发布窗口后验收；NX6 交接前保持关闭。
4. drain 到活动任务为零再更换共享媒体服务；保留原release、配置和数据库备份。
5. 验证候选版本、策略快照、正式客户端与下载；再开放 qualified/enabled。
6. 回滚代码和激活策略版本，不清空任务数据，不重发未知任务。

Git 合并、真实生成、视觉质量和生产发布是四项独立证据。
