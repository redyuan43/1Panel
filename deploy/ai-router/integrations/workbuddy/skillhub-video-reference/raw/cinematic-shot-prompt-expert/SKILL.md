# 电影级镜头提示词专家

本技能是「**视频拆解**」与「**电影镜头库**」的融合体，提供一条完整的创作闭环：

```
用户给一段视频 / 一个分镜意图
        ↓
【拆解】按时间轴逐帧拆解镜头语言      ← 逆向工程
        ↓
【定功能】明确这一镜的叙事功能        ← 开场/转场/打斗/情绪…
        ↓
【选镜】查询 50 镜镜头库，按功能检索   ← 电影镜头库（不凭空现编）
        ↓
【适配】替换占位符 + 场景词收敛 + 模型裁剪
        ↓
【输出】成品电影级生成提示词（分时镜头清单）
```

**核心原则：先拆解、再选镜、后适配。** 任何视频任务，要么拆一段已有的视频，要么定一个分镜意图，但要输出成品提示词必须落回镜头库——不凭空现编镜头描述。

---

## 一、拆解输入（逆向工程）

用户提供一段视频（或视频参考链接）时，按时间顺序逐镜头拆解。**只学镜头逻辑和视觉方法，不照抄人物、品牌、台词、具体故事。**

逐镜头解析以下维度（尽可能完整）：

| 维度 | 说明 |
|------|------|
| 主体身份与外观锚点 | 外观、发型、服装、肤色等反复出现的稳定特征 |
| 动作轨迹 | 主体从哪 → 到哪，做什么动作 |
| 表情变化 | 情绪如何随镜头推进而变化 |
| 场景空间 | 前 / 中 / 后景关系 |
| 景别 | 远景 / 全景 / 中景 / 近景 / 特写 |
| 机位与焦段 | 高机位 / 低机位 / 俯拍 / 仰拍；焦段 |
| 构图 | 对称 / 三分法 / 对角线 / 画框式… |
| 景深 | 浅景深 / 深景深 |
| 运镜方式 | 推 / 拉 / 摇 / 移 / 跟 / 升降 / 手持；速度 |
| 光线与色温 | 方向 / 冷暖 / 硬柔 |
| 材质 | 画面里的材质质感 |
| 节奏 | 快切 / 慢放 / 一镜到底 |
| 转场 | 硬切 / 叠化 / 闪白 / 匹配剪辑… |
| 特效与环境声音 | 粒子 / 烟雾 / 水花；环境声 |

**输出完整镜头时间轴。**

---

## 二、定叙事功能（先问这一镜要干什么）

拆解完 / 拿到意图后，先确定这一镜或这段的**叙事功能**，再决定从镜头库选哪个镜：

- 开场定调 / 场景过渡 / 追逐打斗 / 心理外化 / 空间交代 / 人像造型 / 氛围填空 / 收尾留白

信息不足时先问清三件事，不要硬猜：
1. 这一镜 / 这段的**叙事功能**是什么？
2. **目标模型**：MiniMax H3（≤15s）/ 可灵 / 即梦 / 混元 / 清影 / Vidu / Runway / Veo 3 / Sora / Pika / Seedance
3. **画幅**：16:9 横屏 还是 3:4 竖屏

---

## 三、查 50 镜镜头库，按功能选镜（不凭空现编）

从 `references/50镜提示词库.md` 的「一、50 镜快速检索表」按叙事功能检索，一栏通常有 2–5 个候选。**按功能查，不按编号背。**

给出 **3-5 个候选 + 推荐 1 个**，输出格式：

```
【叙事功能】xxx
【推荐】第 N 镜 · 镜名 —— 一句话推荐理由
【备选】
- 第 N 镜 · 镜名 —— 适用条件 / 与主推的差异
- ...
【组合建议】若这是连续段落，给出 2-4 镜的排列顺序与节奏
【坑】该模型/画幅下的具体风险（时长超限 / 竖屏重排 / 多运镜冲突）
```

组合套路见 `references/组合与纪律.md` 的「二、镜头组合套路」（实战配方：15s 开场、人物首次亮相、打斗段落、反转揭示、大场面交代、抒情留白、全片收尾）。

---

## 四、落地：替换占位符 + 场景词收敛 + 模型适配

选定镜头后，将这镜的成品提示词落地：

1. **取正文原文**：从 `references/50镜提示词库.md` 的「二、50 镜完整提示词原文」取该镜。
2. **替换 `[角色名]`**：换成具体人物。
3. **替换 `[场景：…]`**：换成具体场景。
4. **场景词收敛**：同一条片子的场景词（古寺 / 旧公寓 / 废墟 / 赛博城市 / 沙漠）必须统一成一套，先定世界观词表再套镜头模板，否则模型串场。
5. **按目标模型裁剪**：参考 `references/组合与纪律.md` 的「三、模型适配要点」与 `ai视频提示词架构师` 的多模型适配表。

---

## 五、三条硬纪律（违反必翻车）

1. **一镜一动词**：推 / 拉 / 摇 / 移 / 跟 / 升 / 降，一镜只保留一个主运镜，其余删掉。多运镜会让模型抽风。
2. **布光镜不加运镜**：41-48 号人像布光镜全是固定机位，加运镜会破坏光位关系。
3. **氛围镜当调剂**：32-39 号八条氛围镜是万能填空，任何段落缺过渡都能插，但连续超过两条会拖节奏。

---

## 六、模型适配速查

| 模型 | 约束 |
|------|------|
| MiniMax H3 | 单段 ≤15 秒；21 号长镜头（45s）必须拆镜；升格/降格保留原词即可（是风格暗示非真帧率） |
| 可灵 | 参数化运镜（推拉摇移升降+幅度）；中文友好；剧烈运动易翻车（翻倒/坠落拆成"倾斜+贴地"两段）；无原生音频 |
| 即梦 / 混元 | 中文友好；对"运镜幅度"有专门参数；多镜头需分段 |
| Veo 3 / Sora | 英文；`[shots]` 多镜头块语法；长镜头连贯运镜强项；H3 用分时镜头清单 |
| Seedance | 中文友好；2K；30s 版可两镜合一；会过滤真实人脸照片输入 |
| 通用 | 若模型只支持 5s / 10s 档，优先保留运动与光位描述，砍掉时长数字 |

更多模型语法要点见 `ai视频提示词架构师` 技能的多模型适配层。

## 七、已知素材缺陷（用前必查）

原始素材是「先定镜头模板、后灌场景词」生成的，**6 处场景标签与描述互斥**：33（科幻标签配古寺檀香）、35（沙漠标签配古寺覆雪）、37（科幻标签配山门）、39（惊悚标签配经书）、43/44（场景标签与 41/42 重复）。
直接引用时**必须按实际世界观改写场景词**，别照抄。

## 八、与其他能力的分工

- **ai视频提示词架构师**：负责逐帧拆解与多模型适配（本技能融合其拆解层）→ 本技能给它供候选镜 + 落地成品。
