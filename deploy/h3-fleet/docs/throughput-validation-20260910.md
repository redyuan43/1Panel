## 准入算例

```text
projected = effective_working_set + running_remaining + candidate_budget + global_margin
effective_working_set = current - factor × clean_reclaimable_inactive_file
```

仅为明确假设的算术演示：current=51.6GiB、clean inactive file=44GiB、factor=0.5、
candidate=18GiB、global margin=2GiB。

- 没有运行任务剩余预留：51.6−22+18+2 = 49.6GiB。
- 还有一路需要保留18GiB：49.6+18 = 67.6GiB。
- 还有两路各需保留18GiB：49.6+36 = 85.6GiB，必须拒绝。
- factor=0且无运行预留：51.6+18+2 = 71.6GiB。

这些数字只判断内存算术门，不代表 Swap、PSI、主机可用内存、显存及稳定窗口通过。
历史51.6GiB快照缺少memory.stat，不能把假设44GiB当作其真实缓存，更不能回填证据。
